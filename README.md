# TextRelay Windows 客户端

[下载最新客户端](https://github.com/MidiAug/TextRelay-releases/releases/latest)。首次从 ZIP 解压运行 TextRelay.exe；从 2.x 升级先正常退出旧托盘，已有配对保留。

复制后单击托盘发送，右键打开状态窗口，接收自动写入。3.1 增加远端→个人端的低开销无损压缩，本机客户端解压，反向保持原文；旧版回退。保留密文分片缓存、对端写入确认、状态图标和签名校验的一键更新。安装 3.0 后可直接点击“检查更新／更新并重启”。

两端推荐运行最新版。正文上限 256 KiB；服务器只暂存密文，密钥与解密重组留在客户端。GitHub 只分发通用程序，不中转剪贴板。

下载包不包含配对凭据、私钥或工作资料。更新签名不等于 Windows Authenticode 签名；设备下载与应用控制仍然适用。没有完成所有受管环境的实际验证。
